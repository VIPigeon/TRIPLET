
## Как запустить
1. клонируй репозиторий
2. В репозитории валяется два исполняемых файл tic80 и tic80.exe (для линукса и винды соответственно)
3. С помощью исполняемого файла запустите файл TRIPLET.tic

## Как играть
Бро, просто используй мышку

## Некоторые важные недоработки, которые следует учитывать
1. По умолчанию все настройки выключены. Это недоработка текущей версии. 
2. Музыки нет. Но звуковые эффекты работают :3
3. Пока анимация окончания уровня не закончится, прохождения уровня не засчитается. извините.
4. Время, необходимое для получения наград за время, я выставлял на глаз.
